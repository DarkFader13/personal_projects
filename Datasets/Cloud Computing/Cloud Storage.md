### Cloud Storage Types:
- Direct Attached Storage: Storage presented directly to a cloud-based server, often within the host server chassis or the same rack.
- File Storage: Presented to compute nodes as Network File System (NFS), connected over standard Ethernet network.
- Block Storage: Presented to compute nodes via high-speed fiber connections, provisioned in volumes and mounted onto compute nodes.
- Object Storage: Accessed via API, doesn’t require an underlying compute node, offers infinite capacity, pay-as-you-go model, slower read and write speeds compared to other types.

### Content Delivery Network (CDN):
- A distributed server network that accelerates internet content delivery.
- Delivers temporarily stored or cached copies of website or media content to users based on their geographic location.

### Blockchain
**1. Definition and Structure:**
- Distributed digital database comprising linked blocks of transaction records.
- Each block contains transaction details, timestamp, and link to the previous block.
- Resistant to data modifications, ensuring reliability and anonymity.

**2. Trust and Verification:**
- Blockchain employs algorithms to confirm transactions without the need for intermediaries.
- Transactions are shared among multiple parties, preventing alteration of data.

**3. Real-World Application:**
- Illustration with a house purchase scenario, emphasizing the need for trust and proof of history.
- Traditional centralized ledger system replaced by blockchain for direct, trusted transactions.

**4. Characteristics and Advantages:**
- Open and distributed nature enables accessibility and transparency.
- Eliminates reliance on third-party authorities, reducing transaction time and fees.

**5. Impact and Potential:**
- Revolutionizes transaction processes across industries, including finance, asset services, agriculture, and supply chain.
- Disintermediates established players, transforming transactional dynamics.

### Internet of Things

**1. Definition and Scope:**
- Network of physical objects embedded with sensors, software, and connectivity.
- Enables data collection, exchange, and autonomous action with minimal human intervention.

**2. Pervasive Presence:**
- Found in both industrial sectors and everyday life.
- Devices range from smartphones and computers to household appliances like TVs, cars, washing machines, and fridges.

**3. Household Integration:**
- Connectivity enables remote monitoring and control of home devices.
- Examples include Nest for temperature control and home security systems.

**4. Interconnectivity in Industries:**
- Revolutionizes industries like agriculture and transportation.
- Monitors animal health, crop yield, traffic flow, and enhances connectivity in transportation systems.

**5. Data Abundance and Cloud Reliance:**
- Continuous data collection escalates the reliance on cloud services for storage.
- Objects become aware of needs and autonomous in action, such as placing orders online.

**6. Growth and Opportunities:**
- Rapid increase in IoT devices, averaging 7-10 devices per human.
- Opportunities exist in developing unified IoT approaches and interfaces for seamless data integration
