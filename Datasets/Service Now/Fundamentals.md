## Next Experience, Navigation, and Access
>Now Platform User Interface (UI) is called the **Next Experience**. The Next Experience unifies your instance and enables you to explore apps and access items for your daily tasks.

**Navigate the Next Experience UI** 
- All Menu: access to all applications and modules they contain. An **application** is a group of modules (or pages) that provide related information and functionality in an instance.
- Filter Navigation: quickly navigate to applications and modules
- Refresh or pinning the All Menu: If you want the menu to persist, select the **Pin** icon
- Adding and customizing favourites - Star icon next to an application or module, favourites can be re-ordered, edited, or removed from the menu by selecting the **Edit**
- History Menu:  select any recent activity to open the item in the Content Frame. The default is 30 items. Includes lists, records, and homepages. UI pages and other non-standard interfaces aren't tracked.
- Workspace menus: Agents, case managers, helpdesk professionals, and managers use workspaces to help find, research, and resolve issues

**Personalize your instance**
 You can customize the following preference types:
- Display    
- Accessibility    
- Workspaces    
- User Experience    
- Theme    
- Notifications    
- Language & Region

**Common User Interfaces**

- Workspaces: a suite of tools displayed in a single-pane view
- Lists: displays records from a table in the Platform
- Forms: displays fields from one record, where users can view and edit the record data.
	- Related Lists: records in tables that have a relationship to the current record
- Dashboards:  is a custom arrangement of widgets, you can share with multiple users
- Knowledge Articles: are uploaded to the Platform in specific categories to help platform users
- Service Catalog:  can view and request services and product offerings

## Lists and Filters
>View how lists of records are displayed and determine which records appear in a list by applying a set of conditions.

- Change list views
- Sort list data through Column options
- Use the List Editor to perform in-line editing without having to open a record
- Select the Condition builder to apply a filter to a table to isolate a subset of data
- Add or remove tags to categorize, flag, and locate records
- Personalize a list to show or hide fields on a view, as well as change the list column order for the current logged-in user.
- **List Editor** for editing multiple records, all without having to navigate to individual forms
- **Tags** provide an easy way to categorize, flag, and locate records

**List anatomy**
1. **Title bar**: Displays the list title and view name (when not on the default view), as well as search list values. The filter icon allows you to create custom filters on your list. The gear icon allows you to personalize the list. 
2. **Breadcrumbs**: Offers a quick form of filter navigation. Breadcrumbs are created by using the condition builder to apply filters to a list (see next lesson, "Filters and Tags").
3. **Column header search**: Provides a search within a specific column.
4. **Column headers:** Displays the title (field on a form) of the column.
5. **Field value**: Right-click on a field value to access additional actions.

## Forms
>A form displays information through fields and is where agents do most of their work.

Users can only view and edit the fields in a record they have access to. Related lists display records from tables that have a relationship to the current record. Related lists will only appear on a form if the record has already been saved to the database.

 **Formatter** is an element used to display information that is not a field on a record. For example, the Activity Stream or Work Notes/Customer Comments. Formatter elements cannot be exported to PDF. When exporting PDF data from a form, any formatter elements added to the form are not displayed in the PDF output.

On a form, you have access to links to related records. **Related links** are a way to view more data about the selected record that may not display on the form. **Related lists** show records from tables that have a relationship to the current record. Related lists are presented as tabs at the bottom of the form view. **Templates** allow fields to be populated automatically, simplifying the process of generating new records.
## Tasks
>Defined activities in the Platform that people do to complete their work.

A **task** is any record that can be assigned to or completed by a user in ServiceNow.  It's not good practice to assign **roles** to individual users. For organizational practices, it's best to assign roles to a group that contains users. The **User Presence** feature facilitates synchronous collaboration within one record. See who is online, view their current status, and what they are viewing or editing, all in real-time. To keep up with what is changing in a record, select the **Show Activity Stream**. **My Work** is a list of all active tasks assigned to you; **My Groups Work** is a list of all active tasks assigned to your group(s) but not yet assigned to an individual. 

On a record, you can use the **Notes** tab to communicate to stakeholders and document task activities throughout the task's lifecycle. The **Show all journal fields** icon allows you to display multiple fields under the Notes tab, including **Work notes** and **Additional Comments**  (Customer visible). The **Activity Stream inline editor** enables users to contribute to work within a record without opening a form. The **Show one journal field** can be enabled to only display the Work notes field.

Transform your lists and forms into an interactive graphical experience using **Visual Task Boards (VTBs)**. There are two types of VTBs: **Freeform** and **Data Driven**.
- **Data Driven:** Allows you to add tasks to a flexible or guided task board. You may not change the title of lanes presented in a Data Driven Board
- **Freeform:** Use Freeform boards as your personal organizer, creating individual tasks of any kind and freely adding, removing, and modifying cards and lanes.
## Platform Analytics
>Create and distribute visualizations that show the current state of instance data.

ServiceNow data and can be viewed and analyzed (in real-time or over time) by you and your colleagues. Visualizations can be run manually or scheduled to run automatically.

Types of visualizations available:
- Basic Charts: Donut/pie/semi-donut/Funnel/List
- 2D charts: Bar/Column/Histogram/Pareto/Box
- Times series: Area/Column/Line/Scatter/Spline/Step
- Multi-dimension: Pivot-table/Heat-map/Bubble/Calendar
- Scores: Single Score/Dial/Gauge/Score Card

Platform Analytics provides information about performance **iteratively, over time for data visualizations and dashboards**. **Dashboards** enable you to display multiple Platform Analytics, data visualizations, lists, and other widgets on a single screen.
## Knowledge Management
>Allows for the sharing of information in the Platform through articles for self-help, troubleshooting, and task resolution.

**Knowledge Management** allows users to create, categorize, review, approve, and browse important information in a centralized location that is shared by the entire organization. Each organization can have their own **Knowledge Base (KB)** with flexible controls over who can see the information and who can help develop its content.

The Knowledge homepage displays knowledge articles organized by **Knowledge Base** and **Category**. Administrators can create multiple Knowledge Bases and assign them to individual users in the Platform. This is called **User Criteria**. *A Knowledge article can only be associated with one KB*.
## Service Catalog
>You can browse catalog items to request services and product offerings in the Platform.

The Service Catalog is a robust ordering system for services and products offered by various departments for users. Once a catalog item (requests, requested items, and/or tasks) has been ordered, you may check on the status of the item
## Virtual Agent
>Virtual Agent makes it easy for employees and customers to resolve issues fast and get what they need. It allows users to unlock productivity through a friendly messaging interface, powered by artificial intelligence (AI).

**Virtual Agent (VA)** is a friendly messaging interface that provides immediate help in the Platform. Through live agent support, users have the option to switch to a human agent for assistance at any time, ensuring they receive the help they need.
