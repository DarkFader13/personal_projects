## **Overview**
Data analysis focuses on the tasks of cleaning, modelling, and visualizing data. Core components of analytics are divided into the following categories:
### 1. **Descriptive Analysis:**
What has happened based on historical data. Common measures include averages, quartiles dispersion, and skewness
### 2. **Diagnostic Analysis:**
Why events happened based on descriptive analytics. Such as root cause analysis, principal component analysis  
### 3. **Inferential Analysis**
Involves making inferences, or generalizations, about data. Common measures include Hypothesis Testing, Confidence Intervals, and Regression Analysis.
### 4. **Prescriptive Analysis:**
Actions to achieve a goal using insights. Such as Financial planning, Pricing optimization, Risk mitigation, Operational efficiency, Resource allocation
### 5. **Predictive Analytics**
Analyzes historical data and trends to suggest what could happen next. Such as sales forecasting, and disaster/failure prediction 
### 6. **Cognitive Analytics:**
Draw inferences from existing data, derive conclusions based on existing knowledge, learn what might happen if circumstances change. Such as sentiment analysis, personal recommendations, autonomous vehicle decision-making
### **Data Analysis Process:**
- Developing an understanding of the problem and the desired outcome.     
- Setting a clear metric for evaluating outcomes.     
- Gathering, cleaning, analyzing, and mining data to interpret results.     
- Communicating the findings in ways that impact decision-making.

## Data Structures:
#### Structured Data:
Data which is well organized in formats that can be stored in databases.
#### Semi-Structured Data
Data which is partially organized and partially free form.    
#### Unstructured Data
Data which can not be organized conventionally into rows and column

## Data Repositories

### 1. **Databases**
Can be relational or non-relational, each following a set of organizational principles, the types of data they can store, and the tools that can be used to query, organize, and retrieve data.
### 2. **Data Warehouses**
Consolidate incoming data into one comprehensive storehouse.  
### 3. **Data Marts**
Essentially sub-sections of a data warehouse, built to isolate data for a particular business function or use case. 
### 4. **Data Lakes**
Serve as storage repositories for large amounts of structured, semi-structured, and unstructured data in their native format. 
### 5. **Big Data Stores**
Provide distributed computational and storage infrastructure to store, scale, and process very large data sets.


## Data Wrangling 
An iterative process that involves data exploration, transformation, and validation.  

Transformation of raw data includes the tasks you undertake to:
- **Structurally manipulate and combine** the data using Joins and Unions.    
- **Normalize data**, that is, clean the database of unused and redundant data.    
- **Denormalise data**, that is, combine data from multiple tables into a single table so that it can be queried faster.     
- **Clean data**, which involves profiling data to uncover quality issues, visualizing data to spot outliers, and fixing issues such as missing values, duplicate data, irrelevant data, inconsistent formats, syntax errors, and outliers.    
- **Enrich data**, which involves considering additional data points that could add value to the existing data set and lead to a more meaningful analysis.

## Communications/Visualisations

**Communicate your findings impactfully:**
- Ensure that your audience is able to **trust you, understand you, and relate** to your findings and insights.    
- Establish the **credibility** of your findings.    
- Present the data within a **structured narrative**.    
- Support your communication with **strong visualizations** so that the message is clear and concise, and drives your audience to take action.    

**Visualizing data:**
For data visualization to be of value, you need to:
- Make visuals **easy to comprehend, interpret, and retain**.
- Think about the **key takeaway** for your audience.    
- **Anticipate** their information needs and questions, and then plan the visualization that delivers your message clearly and impactfully.
